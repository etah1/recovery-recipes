# Recovery Recipes

A React and Vite site for Recovery Recipes, an organization sharing accessible meal ideas and resources for people facing food insecurity after hospital discharge.

## Available Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Project Structure

- `src/components` contains shared layout pieces such as the navbar, footer, router, and scroll behavior.
- `src/pages` contains the page-level views and their styles.
- `src/assets` contains images currently used by the site.

## Development

Run `npm run dev` to start the local Vite server. Run `npm run build` before deploying to confirm the TypeScript and production build both pass.
